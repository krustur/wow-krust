# wow-krust

Krust addon source for WoW Forever.

## Install to WoW Forever (Windows)

1. Open `install-wow-forever.bat`.
2. Set `WOW_FOREVER_PATH` at the top to your active WoW Forever install path.
3. Run `install-wow-forever.bat`.

The script copies `addons\Krust` into `<WOW_FOREVER_PATH>\Interface\AddOns\Krust`.
